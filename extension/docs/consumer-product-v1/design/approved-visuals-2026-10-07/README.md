The product intent and later owner decisions control behavior.
2. Compare real current extension screens and relevant interaction states with the actual full-resolution PNGs and original Review/Prototype HTML, at equivalent viewport, theme, text scale, representative state and user data.
3. Context's production reading preference **17 px / 680 px** explicitly supersedes the early package's **16 px / 800 px** specimen; do not change global preferences to match old images. Settings' latest AI Organize style amendment changes the canonical row inventory beyond the original frozen pack.
4. Treat source packages as historical approved visual references, **not** as proof of implemented features, live connections, permissions, paid models, or finished production UI. Work from current code and test the real extension. Synthetic demo names and connected states do not imply real personal data or active integration.
5. Do not commit real archive data, identifying user screenshots, API keys, accounts, cookies, session data, raw chats, or font binaries. Changes to these approved original files require a new, explicitly approved design version.
