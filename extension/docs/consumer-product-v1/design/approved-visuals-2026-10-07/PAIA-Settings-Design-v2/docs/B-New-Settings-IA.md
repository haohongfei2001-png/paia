## 2. 正常文案

“保存我的 AI 输入”辅助说明：保存你在支持的 AI 中发送的文字。首次同意说明明确：普通聊天中已发送、已显示的用户文字，默认不保存临时聊天、草稿、完整 AI 回复或附件正文；恢复可能收录当前仍显示的旧输入。

“智能过滤”辅助说明：弱化明显的操作性输入，原始内容仍保留。它不是保存开关，不改变来源、移除状态或 AI 授权；用户编辑和保留优先。

“AI 上下文”：管理 AI 可以知道的信息和可以读取的思想。Settings 不展示卡片正文、Topic 胶囊、连接授权矩阵或第二处访问管理。

“下一句建议”：根据新完成的 AI 回复，在本机临时提供建议。首次开启时才详细解释范围；关闭立即停止新的读取并清空当前建议，不影响普通复用。

“隐藏内容预览”：在列表和搜索中隐藏正文摘句。不是加密/截图保护等说明放帮助，不占常态两三行灰字。

## 3. 视觉与响应式

继续使用当前 PAIA 的白底/深色语义角色、主导航、标识、衬线标题、正文与元信息字体、蓝色 focus/选中态、轻分割线、6px 控件圆角。不以大卡片围起每组，不把 Prompt 的跨站毛玻璃复制到设置页。

宽屏维持主导航与轻量设置目录，内容按当前 PAIA 轴线排列；组标题、行标签和值对齐。字号预览使用真实四档，但设置页本身仍用 UI 字体角色。行高由内容决定，不硬裁切长中文或 English。

低于 1024 CSS px，设置目录与组页堆叠；进入后“← 设置”。200% 文字可更早触发堆叠，保留实际文字放大，不用缩小字体抵消。320px 不横向滚动；label/value 自然换行；开关仍为至少 44px 可点击目标。没有第三、第四层侧栏。

选择项在轻量对话框内，打开后 focus 到当前选项，键盘可访问，关闭回原设置；窄屏对话框自然滚动。Settings 组切换和跨模块返回使用现有导航 owner，并保留组、滚动和焦点。进入/退出设置不丢 Reader 或 Prompt 的未保存文字与 IME。

## 4. 状态与数据风险

读取失败不是关闭；未连接不等于权限已知关闭；Prompt 支持网站不等于外部 AI 连接。只有持久化成功才能反馈已保存；失败保持已确认值并可重试。隐私读取失败不能临时暴露上次隐藏的预览。

已有备份恢复在确认前不改变活跃档案；临时校验分段不等于已恢复。空库、互不冲突合并、替换各自保留适用范围。替换需独立影响说明与确认，合并遇冲突不悄悄写覆盖，失败保留当前库。恢复不会重开外部授权或下一句建议。这里没有创建/导出备份。

已移除内容只统一找入口。Input 恢复、Topic 容器/关系恢复、Entry/Placement 恢复仍调用真实 owner，不复制正文、不丢人工意图、不复活永久删除，不更改 AI 访问。待确认导入归属不属于已移除列表。

没有 Settings 版本历史说明、自动保存版本行、retention/prune 或笼统永久删除入口。版本在内容自身。合法的 Source 永久删除在具体 Source 上预检影响范围；混合人工派生边界不明确时继续拒绝。

正常不展示 Diagnostics。确认发生对应索引/数据问题后才在相关位置显示一项修复；超时不能被当成损坏。修复成功清除过时警报，失败不冒充已修复。
