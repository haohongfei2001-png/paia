## 1. 当前产品与 UI 合同

### 1.1 四个对象与原有语义不变

| 卡片 | 职责 | 数据归属 |
|---|---|---|
| 我的信息 | 本人相对长期稳定的事实与背景 | 独立可编辑 Context Items |
| 我的规则 | 回答、表达、协作方式及长期自然语言规则/偏好 | 独立可编辑 Context Items，不新增偏好卡 |
| 我的现在 | 当前阶段、重点、目标和正在解决的问题 | 独立 Context Items，不变成待办、项目管理或进度看板 |
| 我的输入 | 可选择向 AI 开放的思想库 Personal Topics | 稳定 Topic ID 与访问状态；不复制 Topic 正文 |

前三卡新增、改写、移动、删除及撤销不反写 Source、Working Input、Thought 正文、主题组织或原始时间。依据用于追溯，不变成双向正文绑定。回答/协作偏好仍由 Rules 语义负责；原型中的示例分组和句子不是重新划分数据职责、自动重分类用户旧内容或硬编码分类的许可。

普通 Topic off 仅停止该主题深入读取，不自动删除或关闭独立保存的前三卡内容；外部请求不能临时从关闭主题提取新信息以绕过限制。永久删除、强制禁止、来源资格及当前 B-02 衍生清理约束仍受原安全 owner 管理。

### 1.2 首页：有内容的蓝白四卡，而非功能说明墙

保留 2×2 顺序：我的信息 / 我的规则、我的现在 / 我的输入；窄屏单列。保留 PAIA 既有三入口 档案 / 思想库 / 用于 AI 和次级设置，不增设第四个 AI Context 导航、账户/Profile、侧边统计或新 shell。

页面采用适度的 AI 上下文标题、短说明和当前空间搜索。卡片上方是轻量范围说明、真实连接入口和总访问开关；不照搬官网营销标题、倾斜展示底板、巨幅插画、仪表盘、活动记录或长期占位的会员推广列。

前三卡显示独立 Item 的真实短正文预览和实际条目数，替代旧版只显示类别概览、不显示正文的限制。原型起始呈现为前两条的有限行数；截取保留原话、否定和条件，不用 AI 摘要冒充原文。完整文字始终在详情可达。隐私状态不妨碍本人本地阅读，但此处不把本地可见误称外部已可读。

我的输入显示少量真实已选 Topic 名及已选/总数。没有选中主题时明确表示未选择；没有 Topic 时显示诚实空态，不植入示例分类或虚构来源。图标、计数、章节线索和预览均从实际 owner 获得，示例中的 3 条、6 个等不是产品常数。

**卡片内容入口与访问开关严格分开。** 内容区进入正常二级页，权限位于卡片底部独立控制区。点击打开、选中文字、查看未开放内容都不产生授权；开关不顺带导航。禁止嵌套交互元素或整卡点击吞掉开关、复制、键盘操作。

使用蓝白近白底、柔和渐变、通透白卡、细淡蓝边、克制阴影和圆角；内容比装饰更醒目。四卡比例保持本原型，不盲目套用思想库的三列/内容瀑布流。可因字号、长文和窄屏自然增高，不用裁切或无意义空白追求固定尺寸。

### 1.3 正常详情页与直接编辑

前三卡打开后为返回/面包屑、卡片标题、当前卡搜索、独立卡片访问状态、轻量操作行和连续可编辑正文。采用轻量分组标签与正文横向对齐；窄屏标签放在正文前。不构造一行一个表单、Edit → Form → Save、多页审批或另一份 Context Builder。

点击正文可直接改写；改动经现有可靠写入路径自动保存，不以单独 Save 按钮作为每次编辑前提。原型中的 contenteditable 和 700ms 定时仅是样机手段，不替换生产 EditorSession、事务、revision/CAS 或持久 ACK。Enter 插入段落，IME 组合期间不提交。保存成功必须得到持久确认；存储受限、失败、冲突时保留草稿，提供重试与安全复制，不伪称已经持久保存。

添加、复制、查看依据、撤销修改、重排、删除与撤销跟随 Item 出现；键盘/触屏不能依赖 hover 才可用。查看依据为按需层，不永久占据第三列。手动内容没有档案来源时如实说明；缺失/已删除来源不是可以伪造引用的理由。分组是轻量阅读组织，不变成强制目录树或新产品分类。

保留原先获批准的共享阅读设置：当前标准角色 **17px / 680px**，实际用户保存的字号/正文宽度优先。新原型的默认 16px 与页面容器宽度是样机值，不撤销此前明确阅读偏好。使用新构图和层次适配现有读写设置，而非重置全局字号。

### 1.4 我的输入：主题列表、搜索、已选视图与本地核对

替换旧的无搜索胶囊场：左侧为 Topic 名及真实章节线索，右侧为独立访问开关。全部主题 / 已选用 是本页轻量过滤，不是多 Library、授权矩阵或按 AI 分开的规则集。默认顺序继续来自 Thought owner；搜索和开关不改持久顺序。

这里的局部搜索可覆盖本人合法可读的 Topic 名、Section 和正文，包括未向 AI 开放的 Topic。复用 Thought 的有界查询与资格判断；没有内容完整索引时如实表示覆盖，不用仅搜索已挂载几条冒充全库。返回匹配的真实 Topic/Section/Entry，不复制正文到 Context 数据层。

点击 Topic 可在按需只读面板核对本地内容，未向 AI 开放不等于本人不能看。核对、搜索、复制单条本人文字、查看依据都不是授权写入。提供安全返回/焦点恢复；长主题用有界连续读取，保留真实末尾、失败/重试/不完整状态，不把卡片摘要当完整正文。

新 Topic 默认关，纯改名保持同一身份设置；新身份、拆分、合并、重建不得继承更大许可。本人预览与外部检索是两个调用身份边界，不能让外部 caller 利用本地预览入口读取关闭主题或 Archive。20/50/144 Topic 的原有规模覆盖保留，不缩成原型 6 项。

全部视图中改变开关不重排。已选用过滤中关闭一项可以在确认提交后移出当前结果，但须恢复到相邻可见控制/原锚点，保留剩余项顺序并支持返回全部；不能让焦点丢失或在同一次点击中误操作下一项。

### 1.5 权限选择、连接状态、实际读取分别表达

新用户默认保持 **全局关、四卡关、新 Topic 关、无连接**。完整示例的预开放状态仅供设计演示，不是安装初值。关闭全局保留 Card/Topic/连接选择，关闭输入卡保留子选择；打开下级不暗开上级。恢复全局只恢复原本已选范围，不重新开启用户关掉的条目。

权限生效关系不变：

```
外部浅层读取 = Global 开 ∧ 连接有效且可读 ∧ 对应 Card 开 ∧ Item 合格
外部深入读取 = Global 开 ∧ 连接有效且可读 ∧ Inputs Card 开 ∧ Topic 开 ∧ 内容合格
本地范围预览 = 本人的本地查看身份 ∧ Global 开 ∧ 对应 Card/Topic 选择 ∧ 当前资格与强制限制
```

无连接时可以配置范围，但不能写成已连接、已发送或 AI 已经读取。副标题/状态要区分仅自己、已选但上层暂停、按设置开放但未连接、真实连接可用/暂停/撤销/待确认。失败时保留实际已确认权限和未确认提示，不能乐观显示全部停止或自动重开。

所有有效 AI 连接继续共用 PAIA 级范围，不新增 AI × Topic 矩阵。Rules 正文只是用户内容，不是修改授权、写入其他系统、读取其他账户的命令。权限须在可信服务执行，不能只靠 DOM 隐藏或开关颜色。

关闭普通权限不删除本地内容，撤销阻止之后的读取而不能收回已经送达外部的副本。当前删除、强制 deny/never、来源 purge、revocation generation 等更强限制仍优先。

### 1.6 按需“AI 可读内容”预览与复制

保留本原型的可读范围预览入口，按需打开抽屉，不形成永久第三栏、新的配置步骤或访问前置审批。展示前三卡允许的实际 Items 和输入卡下明确选中的合格 Topic 内容；区分卡片/主题、正文/引用/AI 文本及实际覆盖，不自动融合为新的事实稿。

**它是按当前设置生成的本地范围预览，不是某个外部 AI 的接收回执。** 没有连接时明确未连接/未发送；总开关关闭时不显示“可读正文”，但保留底层选择。本人仍可在本地详情/Topic 核对中阅读有资格访问的资料，两种视图不得混淆。

复用唯一权限/资格解析 owner，禁止在 UI 另写一个与可信服务可能分叉的简化授权器。预览和复制在执行时重验当前持久权限 generation、Item/Topic revision、删除/强制限制与内容资格；已打开抽屉期间发生撤销、编辑、移动或 purge，要失效/刷新受影响显示和复制载荷，不允许从陈旧缓存复制仍标为开放的内容。

原型中的“复制可读内容”作为用户显式、可选的当前范围剪贴板动作保留。只复制经当前范围确认的内容，不自动发送、不生成下载/导出文件、不恢复批量归档导出、Package/Ready/Export，也不成为日常使用 AI 的前置流程。说明复制到其他软件后由用户控制去向、无法召回；复制失败提供真实失败/手动安全复制，不虚报成功。

大范围使用有界加载和明确覆盖；不能一次无界挂载/拼接全库，也不能把已加载前缀标成完整副本。完整复制须在明确操作下受控遍历至真实合格末尾且期间保持版本/权限一致；达不到时说明实际范围或拒绝该次完整复制，不能偷偷补取 Archive、不显示假完整成功。普通剪贴板能力只作用于这个已批准范围，不恢复被取消的通用导出产品。

### 1.7 搜索范围、导航与草稿

首页搜索仅在 AI Context 空间内检索三类独立 Items 与 My Inputs 所连接的 Thought Topic 合格内容。详情搜索只限当前卡片；输入页只限 Topics。复用已有本地查询，不创建竞争全局搜索、平行正文存储、后台遥测或付费语义检索。普通关闭 AI 外部访问不阻碍本人本地搜索；已删除/不合格记录仍排除。

本地搜索结果可临时替换四卡/详情内容，显示路径和精确短原文。保持查询、过滤、稳定身份焦点与视口锚点；清空/返回/Back/Forward 不丢失草稿，不凭旧 scrollTop 打开已删除记录，不把查询和正文放进外部 URL 或 Sync。

搜索/过滤/开关/打开预览/移动/导航前保护组合输入、dirty draft 和保存失败。不因视觉刷新卸载活动编辑器。生产沿用现有草稿/路由/历史 owner，修补确有证据的缺口；不要把样机简单 history/localStorage 当生产恢复实现。

### 1.8 移到另一张卡片：显式移动，明确目标权限

保留本原型上下文菜单中的前三卡之间移动和组内重排。移动独立 Item，不复制正文，不允许将 Item 移入“我的输入”伪造 Topic。保留稳定身份、revision、来源依据、人工保护和删除抑制；仅修改明确的类别/阅读组织，已有卡片开关不变。

由于卡片访问范围不同，确认界面须展示源/目标卡片的当前权限影响，尤其从仅自己移入已开放卡片会让该 Item 进入选定的对外范围。**明确确认该目标与权限效果后才提交**；不是通过无提示拖动扩大访问。提交按当前 generation/CAS 重验，如果确认期间目标权限或 Item 已变化则安全拒绝/重新核对，不在旧确认下扩大范围。

撤销遵守当前权限、revision 和更强限制，不恢复旧 grant 或覆盖后来人工改动。非拖动的键盘/触屏重排保持人工顺序。类别迁移不是自动重分类或新的跨数据域正文合并。

### 1.9 自动补充、连接和真正完成条件

自动补充入口表达既有 CTX4-05，而不是新算法、更大的默认处理范围或模拟 AI 结果。内部提取许可、外部读取许可、会员权益和费用控制是不同条件；沿用 AI_USAGE 唯一任务/额度/预算 owner，不在 Context UI 新建计费逻辑。无服务、无许可或费用条件不足时如实不可用，本地读写和范围配置继续使用。

保留 CTX4-05 的完整目标：从合格 Inputs 增量提取/更新 Info/Rules/Now，识别本人陈述、引用、假设、AI 回复、否定和不确定性；保护人工新增/修改/删除，不能凭字符串去重声称语义完全正确；真实质量需单独评估。原型点击后出现说明不是实现，也不允许“定时刷新”冒充自动维护。

原型的连接空态不取消既有连接详情、暂停、撤销、重连和首次许可流程。生产仅显示真实可用连接；不能硬编码示例品牌成功，不恢复旧 BYO key/direct transport。实际传输、身份、设备离线和地区等条件须在原边界下验证，不默认批准新的云服务或整库上传。

完整外部体验仍是：获准 AI 先读开放浅层信息，再按需发现/搜索合格的已开放 Thought Topics，读取相关完整用户 Inputs，形成有据回答。不得退回 Archive、Conversation/Project 或任意 Input 接口补尾。用户日常无需进入 PAIA、手选材料、预览/复制或 Review/Ready/Export；剪贴板只是额外手动工具，不能替代真实连接验收。
