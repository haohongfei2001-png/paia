## 1. 首页必须是目录，不是个人信息的裸露展示

### 1.1 四卡职责不变

我的信息维护长期本人事实；我的规则维护回答/表达/协作偏好；我的现在维护阶段性重点；我的输入管理稳定 Thought Topic 的访问选择。前三卡独立 Item、第四卡仅引用，不新建偏好卡、Profile、个人画像系统或正文副本。

### 1.2 默认第一面

保留 2×2 顺序及窄屏单列、蓝白边界、真实连接入口、总开关和卡片底部独立权限操作。前三卡只显示合适的类别级标题/目录：例如个人资料、教育经历、兴趣爱好，而不显示某学校/学历/住址/具体经历/想法。后两组同样只给回答方式、当前重点这类目录线索，不把正文重新概括成一个泄露事实的标题。

优先复用真实现有分组/Section 标题；不硬编码一套强制分类、不自动生成用户事实、不为了填满卡片造空章节。没有适合的安全目录时保留通用卡片入口即可。实际可直达的目录才成为链接；未知目标不能是假链接。首页渲染所需投影以元数据为限，不能在隐藏 DOM、title、aria、tooltip 或 hover 中携带正文。只有主动打开真实内容或提交明确的局部搜索后才展示对应详情。默认进入不自动重开旧私密搜索/正文；明确 Back/history 的既有恢复另行保留。

我的输入可显示真实 Topic 标题和目录线索，不显示其原文/摘要。已有隐藏预览偏好继续生效，但该偏好不是前三卡默认无正文的前提。外部设置为仅自己与本地首页不暴露是两项不同边界。

删除正文后按目录实际高度收紧卡片，不保持旧 211px 内容区或类似大空框，也不新增填充文案。四卡顺序、清晰边界及触控可达性保留。原有必要权限状态和选择不因为简化而隐藏。

### 1.3 详情与阅读

保留正常详情页、当前卡搜索、直接编辑/自动保存、添加、复制、来源依据、修改撤销、组内顺序、跨卡移动确认、删除与撤销。沿用当前 canonical Item/EditorSession/事务/revision/CAS/持久 ACK，不导入样机存储或改写 Source/Working/Thought。

使用共享 UX §3 的普通行距、同条段距与跨条间距。17px 正文以 27–29px 行高作为试调起点；真实字号/宽度/主题偏好优先。修显示层叠加空白，不删除原始换行、代码/诗歌空行，不改变复制、序列化、正文 hash 或来源时间。中文 IME、光标、选择、失败草稿和返回锚点仍完整保留。

### 1.4 输入权限、搜索与范围预览

原计划 §1.4–1.8 的所有非冲突要求继续：真实 Topic 行、全部/已选、合格全量局部搜索、未对外开放内容的本人只读核对、稳定身份授权、受控范围预览与明确复制、跨卡移动目标权限告知/确认和重校验。首页目录不等于取消详情查阅。所有这些入口仍不得成为外部 caller 读取未开放 Topic/Archive 的旁路。

## 2. 不变的权限与数据约束

新用户仍全局关、四卡关、新 Topic 关、无连接。上级暂停保留下级选择；下级开启不打开上级。外部浅读要求 Global、有效连接和对应 Card/Item 合格；深读额外要求 Inputs Card、Topic 与当前内容合格。所有已连 AI 共用一份 PAIA 级范围。普通 Topic off 不删除独立前三卡；永久禁止、来源资格、purge、generation 和当前衍生清理要求仍优先。

隐藏首页正文不变更真正权限，打开目录/搜索/阅读不产生授权。规则文本不是授权命令。保留可信身份、revision/CAS、删除抑制、在途输出失效、缓存/索引/cursor 限制、全量有界遍历和无 Archive fallback。维护提取权限与外部读取权限分开；人工改写/删除优先，无模型时手动功能仍可用。现有跨卡移动、迁移和恢复不得扩大许可或复制正文。
