## 1. Thought Library: no decorative counts or update labels; one activity order

Remove the Topic total beside 我的主题, counts after Section/directory labels, card chapter/item totals, and 今天/昨天/最近更新/date badges used as overview decoration. Do not relocate them into a normal overflow menu or replace them with activity scores. This removes UI-added metadata, not user-authored numbers in titles, scientific/technical subjects, stored timestamps, or counts needed internally for bounded queries and correctness. Necessary search coverage/error/continuation feedback remains truthful; it is not a statistics display.

Home keeps real Topic names, real chapter links, the already approved eligible short expression preview, contextual actions and content-sized blue-white cards. Reader keeps real chapter navigation without trailing counts. This change does not apply the Context privacy rule to every Thought preview, nor remove reliable Input/source timestamps used for actual provenance.

Root order is **one natural automatic activity order**, not a selectable 最近更新 / 我的顺序 pair. Remove the mode selector and root drag/manual-sort interaction. Preserve existing saved root-order metadata non-destructively for compatibility; it does not drive the current root. Human Section/Entry order, names, placement and keep-separate/include/exclude constraints remain protected.

Use meaningful recent user expression: a genuine newly sent Input uses its reliable original expression time; explicit local writing/continuation or substantive saved text edits use the actual acknowledged human event. Rank by the most recent qualified such activity, with deterministic existing-order/stable-ID ties. Do not use raw storage updatedAt, total size, view counts, render/open/search/hover, permission changes, AI organizing, indexing, sync, import/capture arrival time or background maintenance as new activity. Importing old material keeps its original activity evidence; unknown old send times must not become today. Absent qualified activity retains stable fallback order without fabricated freshness. Reuse existing bounded source/revision projections, not a new activity-monitoring or analytics service.

Calculate across the complete eligible Topic set, not only mounted cards. Render a stable ordered snapshot. New activity can reorder at a safe new entry/reconciliation point, never beneath a click, selection, drag, IME or pending editor. Explicit Back restores the recorded result/card anchor and visible order first; do not silently sacrifice return correctness to immediate resorting.

## 2. AI Context: the first surface is a private directory, not exposed facts

The four cards remain 我的信息 / 我的规则 / 我的现在 / 我的输入, with independent bottom permission controls. The first three show **category-level titles or directory labels only**, not Item bodies, sentences, summaries, factual values or first-N-characters previews. Examples of label granularity: 个人资料/教育经历/兴趣爱好, 回答方式/表达偏好/协作习惯, 当前重点/正在进行/近期变化. These illustrate wording, not a compulsory taxonomy or permission to invent stored groups.

Use existing suitable group/section labels where available. Do not manufacture a specific fact-bearing title from the body, expose a school/degree/location/private plan through a shortened heading, or silently rewrite the user's canonical groups. A generic card-level entry is sufficient when no safe meaningful subdirectory exists. Only expose a clickable subdirectory when it resolves to actual content; no fake links or AI classification prerequisite. Plain-label rendering should not mount the private body in hidden DOM, title/tooltip, aria text or a hover preview.

我的输入 may show existing Topic titles/directory cues, not their body excerpts or generated summaries. Honor the separate hide-preview preference and lawful eligibility. Topic titles are not claimed to be encryption or an absolute secrecy guarantee. Opening a card, choosing a real directory entry or deliberately committing a nonempty local search is explicit navigation to content; merely loading/focusing/hovering Home is not. Default first exposure must not automatically reopen old private content/search results. Existing intentional Back/history restoration remains distinct and guarded.

Local visibility and external permission are independent. A Card marked 仅自己 does not justify exposing its full text on Home. Conversely, opening content does not grant AI access. Detail editing, explicit local search, Topic permission list, on-demand source/scope preview and actual connection management remain. Reduce card height to the compact directory content; remove the old body-preview minimum-height requirement without adding filler. Do not simply restore the old visual design.

## 3. Reading rhythm: line, paragraph and separate Input are different levels

Apply one coherent reading rhythm to Archive, Thought and Context prose through the existing shared/scoped roles. **Automatic wrapped lines are close; paragraphs inside one Input have a modest separation; separate Inputs have a more noticeable separation.** Do not give every line/paragraph the outer spacing of an independent entry. Retain unboxed continuous reading and quiet attributable time.

At 17px ordinary body size, approximately 27–29px line height is the agreed tuning starting point, not a rigid clipping rule. Scale with actual saved font size. Check the combined computed line-height, paragraph/block margins, preserved newlines and empty editing blocks: a source blank line must not acquire duplicate large paragraph margins. Reduce the renderer's extra spacing, not the text. Preserve every intentional newline, paragraph, list, poem, code indentation, blank line and copy/serialization result; no normalization/deduplication of the user's text to improve a screenshot. Code/verse keep appropriate distinct rendering where required.

The visual target is ordinary continuous text, not a promise that all authored blank lines disappear. Keep saved font/width/theme, caret/selection/IME, durable edits and source history. Reflow changes no body hash or revision; search offsets/highlight and reading anchors must remain correct. Validate resting and active editing using short wrapping text, two paragraphs, explicit blank lines, long inputs, lists, code, verse and mixed scripts, plus text enlargement and narrow/dark layouts. Do not add a new line-spacing setting.

## 4. Archive: one clickable current-source selector

Replace the ordinary simultaneously expanded provider headings/trees with **one current-source name button**, e.g. a verified `ChatGPT` with a small disclosure indicator. Clicking the name itself opens the source menu. Other actual available sources such as Claude appear there only when supported/available, never as seeded adapters, a permanent second tree or a new row of platform tabs. The current-source tree is Source → Project → Conversation; identities remain provider-qualified. A source Project is not a Thought Topic.

The same menu contains an explicit 全部来源 search choice. It is a deliberate broader scope, not the default pile of all expanded source trees. Maintain one logical selector/query owner. Within an existing view, retain its validated current-source choice. On a fresh view reuse the existing valid source initialization, selecting a single actual source where available, with no host-tab/credential inference or new persistent favourite-source feature. No data means a truthful unselected/empty source state. Unknown/unavailable source is not permission to silently read another source.

Choosing a different source explicitly changes navigator and Archive query scope together, preserves the typed query, clears any incompatible Project restriction and displays matching scope wording even while query text occupies the field. With a nonempty query show that scoped result set; without one leave Main unselected and blank. Never open the first/latest Conversation. Pass existing dirty-work/IME guards before committing the change. Selecting 全部来源 explicitly permits cross-source search; a result retains actual provenance and exact Input identity.

Primary Archive entry is still neutral: empty query, no selected Project/Conversation/Input and blank Main; it may retain the current valid source within existing view-state lifetime. **The old mandatory all-source reset is superseded for this source selector**, not turned into resume-last-Reader. Clear a Project restriction back to its current source; clear text without secretly broadening source; choose 全部来源 explicitly to broaden. Explicit Back/Forward and supported cross-space query handoffs restore their actual recorded all/source/project scope, tree/query and anchors. Reader Find stays current-Conversation-only and independent. Project name and arrow still only disclose children.
