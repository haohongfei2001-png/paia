Safe legacy history decodes; body/command/secret fields are refused. Reload/eviction retains admitted references and loses transient query/extent, never creates content or grants authorization.

`DocumentSearchSessions` holds at most32 owners. Only the active page retains Search DTOs; parked owners retain copied query/cursor/generation/anchor metadata and must re-read on return. Park, invalidation and successful leave clear old result DTOs and DOM. A failed leave retains the current editor and scope. The shared input is disabled during awaited navigation; only the latest navigation intent may re-enable it. Existing save flush, leave guard, conflict, recovery and IME baseline protection remain authoritative.

Root SmartFilter receives its explicit query; it no longer reads a retired DOM search node. Reader uses existing document-scoped paged `SEARCH_INPUTS`, generation fencing, canonical full-domain lookup and exact Input navigation. Reveal uses one absolute immediate scroll rather than competing relative smooth scrolls, and removes the decorative animation over editable prose. Closing search restores the existing pre-search anchor. No semantic retrieval is activated.

Search composition publishes only at completed composition/input; a final compositionend is handled even without a subsequent input event. Over-bound paging metadata drops disposable extent and restarts a fresh page while retaining its query/reference/pre-search anchor; the cache cannot block leave.

One reviewed keyboard delegate chooses the admitted visible result list. Native editable/input/select/textarea Find remains native; composing/key229 events cannot trigger PAIA navigation.
