## Bounds and authority

ContinuousRootReader keeps all visited positions as body-free refs/request
cursors. Only120 compact root/search DTOs plus up to32 focus/selection/open-menu
pins remain resident; pin overflow stops paging. The replay staging Map is
explicitly owned and cancellable. Existing cache overlap plus staged missing
DTOs is bounded by that same window; old non-retained cache and homePage handles
are released before replay. A single incoming bounded RPC page is transient
transport data, not another retained window. An independently reproduced held
backward replay followed by a new frontier page retained160 DTOs on an unpublished
checkpoint; cancelling hydration on both frontier admission/completion and
mismatched-record replacement closes that path and retains its exact regression. Snapshots, pre-search/Back and
bounded root/Topic position cache contain no excerpts or Topic summaries. Hidden
root DOM and cached bodies are released on Topic entry. Prior windows refetch the
exact request and expected refs; a stale authority or changed ref clears the body
cache rather than offset-paging into a different row. Retry is explicit after
same-window failures, including terminal extent. A query cleared before debounce
and a delayed stale-replacement read are separately fenced.

Domain root DTOs omit canonical summary/protection/authorship/countCache. Human
cue and exact excerpt remain bounded and attributed. Recent metadata is body-free.
Search remains lexical; saved-AI matches are paged within the same eligible saved
presentation owner rather than retaining every saved AI body in the root UI.
Search result membership labels remain complete; this is a DTO-count/body-window
bound, not a universal response-byte or many-Topic-membership bound.

Authority uses existing thought/input/revision/recovery and portable-data
metadata. The last transaction fence follows result assembly; saved-AI filter,
Source presence, time and explicit keep changes are covered. Search additionally
binds readiness, so an incomplete cursor cannot become complete while omitting
newly indexed rows behind it. Emitted continuations carry authority. Stored AI
must have the matching Topic identity. countCache and readingActivity are already
excluded from portable Topic Backup fields; their narrow repository helpers
validate exact allowed shapes and unchanged remaining fields while preserving a
prior backupChanged flag. Canonical field changes cannot use these exemptions.

Large-entry reads fence owner/reader/route/serial/id/revision and expression
read-generation before mounting. Expanded full bodies become part of the same
bounded reader and stay editor-owned through benign rendering; a fresh large-only
projection cannot leave an unowned editable node. Resize never writes editability.
