## Ownership and changes

One AppShellController connects the existing route/history owner and explicitly
presents the current route. Archive Navigator mounts into declared root/Reader
slots; it no longer observes and relocates collection DOM. Topic and Context
retain their existing controllers until D2/D4; neither gains a second router.
Settings preferences are extracted without new storage or permission semantics.
The old `core-loop`, `ux-r1-shell-coordinator`, and `archive-shell-chrome`
bootstraps and their obsolete Archive layout rules are retired in this cutover.
The production token roles and 184/160/64 rail, 280/240 contextual column and
1024px sheet boundary implement the frozen responsive contract.

Selection is an ephemeral native DOM snapshot. Alt+S reaches its action toolbar
without discarding the exact Unicode range. Cross-Input selection permits exact
Copy and disables single-input Add actions. Topic/material admission checks the
complete selected body and exact range before and after the existing editor
flush, and refuses a replaced editor. Domain revision/permission guards remain.
No Source/body/schema/provider/budget/permission changes.
