  exact grapheme-safe attributed excerpts or explicit human notes, and honest
  time-role captions replace generated root summaries. Ellipsis is separate UI.

  receipt. Bodies, Source, placements, history, anchors and other preferences
  are not migrated. The old grid toggle is removed; legacy API input returns list.
- A reliable expression timeline reuses the existing body-free Topic generation
  owner, with dated/unknown counts, observed interval, year pages, provider scope,
  revision/generation revalidation and bounded canonical body DTOs. Capture or
  generic createdAt never establishes expression time. Conflicting/ambiguous
  source events remain unknown; invalid dates use the existing historical parser.
- Only a successfully committed nonempty CONTINUE_THINKING creation adds an
  independent-expression marker to its existing operation receipt result. Replay
  keeps the original event time. Excerpts and ambiguous migrated rows do not
  inherit that authority. No new canonical body, store, database version, provider
  permission or B-01 reverse/edit policy is introduced.
- Root excerpts are transient: any library mutation clears their DOM/cache and
  invalidates in-flight root tickets before a fresh read. Source purge must not
  leave a canary in a returned DTO or resurrect it through an old root response.
