grid. Topic and real named Section links retain canonical identities. Untitled
default Sections add no invented heading; empty user-created named Sections
remain visible. Body-free bounded reads draw the ordinary Root, while search

Back and Settings. Explicit sort is a presentation action, never canonical Topic
order. Native links use a strict Topic/Section fragment codec; worker admission
retains exact extension identity, origin, path and query checks. Invalid or stale
targets are refused by the current read owner. Reading font and width preferences
are preserved. The ordinary browser text-selection fixes are compatibility work,
not a title-copy product feature.
