Strict grammar forbids whitespace/BOM/trailing documents/holes; strings reject lone UTF16 and noncanonical escapes instead of repairing text; bounded numbers require finite/nonnegative-zero and exact original JSON.stringify spelling.
```
W = wireOctets + 2*canonicalCodeUnits + 64*valueNodes + 32*containers

```

Returned names include every object key **and every array index plus length**.
