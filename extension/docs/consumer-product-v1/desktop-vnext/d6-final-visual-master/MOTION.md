# Motion specification

Menu/selection appearance120ms; navigator group160ms; route presentation180ms; a validated candidate's separate structure preview220ms. Easing cubic-bezier(.2,0,0,1); travel at most8px. Avoid blur, orbs, glow, particles and perpetual movement. Timings are design targets, not performance measurements.

Running is truthful: keep Current and original readable, show actual request state, and expose only the existing Stop action. Never animate paragraphs as though valid organization exists before a validated result returns. No fabricated percentage and no automatic paid retry.

On validated candidate arrival, a separate preview may open spacing and fade structural headings. Label it as a candidate throughout. Live original/editor DOM, caret, selection and scroll anchors must not move for decoration. Editing/selection interrupts motion immediately. Leaving a view cancels its presentation work, not implicitly the underlying external request. Cancellation/unknown outcome follows the actual job owner.

Reduced motion: no translation/auto-scroll/blur; immediate change or<=80ms opacity. Fast results never wait for an animation to finish. Failed or canceled requests never animate fabricated success. Static O02/O09 artboards cover visible running/failure endpoints; this file defines interpolation and interruption, not new service behavior.
