# Dark master

Four independent dark references cover A02 Reader, T03 dense Topic, O04 Compare and C04 Context Review. Palette and typography are the same component system, not inverted screenshots.

Canvas#171D28, rail#121823, primary ink#E8EDF7, secondary#B0BDD0, divider#303B4C. Selected blue#263B5B; focus/link#94BAFF. Brand#E2A295 remains distinct from warning#E4C387 and danger#F4A2B1. Keep the exact raster logo, including its supplied white field; do not invert or redraw it.

All other dark states derive by token substitution from their mapped light master. Geometry, state, hierarchy, source text, quote roles, decision labels, disabled release reasons and keyboard behavior do not change. Verify status and thin controls against the actually painted background. Do not infer contrast from a transparent ancestor as if it were black.

These are design drawings, not full dark-mode accessibility certification. D7 tests actual production text/control contrast, focused/disabled/coarse states and stored theme changes without remounting an active editor.
