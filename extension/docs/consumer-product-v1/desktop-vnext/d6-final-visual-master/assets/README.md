# Finished visual assets

`visual-masters.tar.xz.001` through `.003` are consecutive byte parts of one lossless XZ/TAR file, not three design versions. `source/unpack_masters.py` joins them in numeric order, verifies the complete SHA-256, and unpacks already-finished images. No image generation, inference, external request, font download or production API is involved.

The archive contains59 standalone SVG artboards, seven multi-view SVG image documents, the gallery and the exact64px logo derivative. SVGs are resolution-independent finished visual images. Every view is a full-window target. The review ZIP additionally includes59 PNG renders.
