## Specification closure is not execution closure

All ten areas now have a normative owner and defined behavior. External/model/device evidence remains NOT_RUN. The production foundation pause remains controlling. B-01/B-02/B-03/B-04/B-05 and their dependent actions are not decided by this design package.

## Completion decisions made here

CD-01: one scoped search in the workspace header, not over a different navigator; independent route queries restore on Back.
CD-02: Original and History are centered modal reading surfaces, one at a time. Their target is explicit; never infer an arbitrary Input from a Conversation.
CD-03: collection pages reveal continuously in batches of 40 with an accessible manual fallback; page size is a presentation target, not a service cap. Existing domain bounds prevail.
CD-04: AI decisions use the existing canonical changed-field unit. A visual subsection does not create a separately committable unit. No invented 18-field backend.
CD-05: candidate choices/Context output drafts remain tab-session-local unless an already-approved recovery owner supports more; no promise of reload survival and no new body store.
CD-06: neutral selected controls with text/check marks; brick accent is identity, not destructive meaning.
CD-07: saved AI presentation can be viewed without a new request; generating/updating is separately confirmed. A new first-generation review boundary is a service integration gap, not a CSS claim.
CD-08: width/type/motion values in UI_SYSTEM are final proposed implementation values within the frozen language, not extracted prior approvals.

## Removed regressions

No Reader composer, fourth column, metadata Inspector, second search, repeated provider badges, statistics sidebar, timeline spine, AI replies as the archive body, or redrawn brand symbol. Design-index links/synthetic labels live outside the product frame. Required counts for coverage or unfinished decisions are allowed; decorative collection counts are not.
