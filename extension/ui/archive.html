了解捕获、删除与本机存储的完整说明
  • 默认关闭。不会读取未发送的草稿、监听键盘、收集 AI 回复或附件内容。仅记录附件与引用是否存在及可信度，供本机轻度过滤判断。
  • 不读取 Cookie、凭证、密码、浏览历史、其他网站、Chrome 配置文件、Keychain、剪贴板或其他本地文件。
  • 捕获和阅读在本机完成，不使用云同步或分析工具。会员 AI 服务和外部连接尚未开放。
  • Temporary Chat 默认跳过；没有正式聊天 ID 或无法可靠识别消息的页面也会跳过。
  • 启用或恢复时会收录当前页面已显示的旧用户消息，包括暂停期间发送、恢复时仍显示的文字。不自动滚动，也不请求服务器历史。捕获时间不是实际发送时间。
  • 仅旁路查看页面自身已收到的有限历史响应副本，精确匹配用户消息的 ID 与时间；不提取或保存响应正文。时间来源不可靠时显示“发送时间未知”。
  • Source Record 原文不可被编辑覆盖。Input Archive 是可编辑的输入文档，Thought Library 是独立思想库。整条删除输入保留原始来源，可撤销或通过版本历史恢复；永久删除来源不可撤销，相关历史不能恢复原始数据。
  • 可以随时暂停。已有 PAIA 备份需先校验、预览，再确认恢复；替换会清除当前库，永久删除标记始终优先。卸载扩展会清除本机档案。存储没有应用层加密。

页面结构变化可能造成漏捕或发送时间未知；扩展不会猜测缺失的来源时间。
