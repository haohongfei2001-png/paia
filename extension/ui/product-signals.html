PAIA · LOCAL TOOLS

本机工具

这里放置低频、可审计的本机能力：产品验证只保存聚合计数；Passport 只保存授权元数据。两者都不保存新的正文副本，也不增加网络请求。

本机产品验证

默认关闭。开启后只记录固定事件名、粗粒度枚举、日期桶与计数，最多保留 90 天；不会保存搜索词、正文、标题、主题名、Profile 名或对象 ID，也不会进入 PAIA Backup。

最近 30 天

产品循环

这些数字只描述可观察行为。例如“切回原文”不等同于拒绝 AI，“重复访问”也不等同于满意；产品判断应结合一段时间的真实使用再做。

统计数据控制

导出的文件只包含本页的聚合统计与 Passport 状态摘要；清空产品统计不会删除档案、思想、Passport Grant 或版本历史。

PAIA PASSPORT · MINIMUM GRANT

AI 权限 Passport

Thought / AI Context Profile 决定“哪些内容可以进入上下文”；Passport 只决定“哪个 AI、为了什么目的、在多长时间内，可以把这个 Profile 生成的 Context Package 带出 PAIA”。Passport 不保存正文。

访问审计

只记录 Grant、Consumer、Purpose、Profile 引用、时间和 copy / markdown 动作；不记录 query 或 Context 正文。

CONTEXT PACKAGE · EPHEMERAL

用 Passport 导出一次 Context Package

先选择一个仍有效的 Grant。PAIA 会用该 Grant 的 Profile 在本机生成预览；复制或导出前会再次校验 Grant。Package 元数据稳定存在于本次预览中，正文不持久化。
