## 功能与边界

已实现弹窗状态/数量/暂停恢复，独立档案页的时间线、聊天分组、搜索、原文阅读、备注、整理版、隐藏、回收站、恢复、永久删除、JSON/Markdown 导出和无正文诊断。

原文与内容哈希不可通过整理操作修改；网页源消息重新编辑发送会形成独立快照。去重跨刷新、重复观察和多标签页生效；同样文字发送两次会留下两条独立消息。

启用/恢复时，会收录当前页面中已显示的普通聊天用户文字，可能包括过去或暂停期间发送的消息。不会请求服务器历史、自动滚动或读取草稿/AI 回复。页面顺序仅是捕获当时已加载用户消息的顺序；捕获时间不是实际发送时间。

Temporary Chat、尚无持久聊天 ID 的首页，以及不确定消息身份/文本容器的情况均跳过。网页 DOM 改版、分支/虚拟化加载和新布局可能造成漏捕，必须手工验证当前 ChatGPT。当前适配器版本为 `0.1.0`。

正文仅持久化到 `chrome.storage.local`。唯一 API 权限为 `storage`，静态内容脚本仅在 `https://chatgpt.com/*` 顶层页面运行；无云同步、网络请求、分析、键盘监听、Cookie/凭证/历史/剪贴板/本地文件读取。扩展在无痕模式不可运行。

删除先进入回收站；永久删除移除正文，保留无正文的去重哈希，防止刷新又收回相同快照。隐藏并非删除。导出是你主动触发的浏览器下载，文件由你自行保管；不要存入源码目录或 Git。无导入恢复功能，卸载前先导出。
