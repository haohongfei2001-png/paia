# Reproduce the frozen experiment

This directory is development-only, excluded from internal and release extension asset allowlists. No real/private text is permitted. Node scripts take a frozen sibling checkout `../paia-ai-context-v0101`; alternatively set `PAIA_RETRIEVAL_MODULE` for run.mjs. The original frozen tag is `checkpoint-v0.10.1-ai-context-quality` (3a58fcd1).

1. `node experiments/intelligence-v0110/run.mjs` runs production lexical; choose an output path with PAIA_BENCHMARK_OUTPUT. Point PAIA_RETRIEVAL_MODULE to frozen baseline or candidate-idf.mjs / candidate-expansion.mjs to reproduce variants.
2. `node experiments/intelligence-v0110/parity.mjs` checks all 824 full ordered ranked objects and alternates benchmark timings. This does not mean all queries have a relevant result.
3. `node --input-type=module -e "import {intelligenceDataset} from './experiments/intelligence-v0110/dataset.mjs';import {writeFileSync} from 'node:fs';writeFileSync('work/intelligence-v0110/dataset.json',JSON.stringify(intelligenceDataset()));"`
4. `node experiments/intelligence-v0110/export-lexical.mjs` exports frozen lexical top-100 IDs for fusion. Source/IDs are synthetic only.
5. Optional explicit development setup: install `model2vec==0.7.0` into an isolated Python environment. This is not an extension dependency. Use Python 3.12 and NumPy as in the original receipt; host architecture affects timing. Then `python experiments/intelligence-v0110/download-model.py --download-public-model /private/tmp/paia-v0110-model`. Pinned asset hashes are verified; no hundreds-MB model or private content is transferred.
6. `python experiments/intelligence-v0110/vector-prototype.py` loads only that local directory with offline mode/socket network block, uses the frozen data and writes a CPU research result. Not a browser/WASM acceptance test. No provider, external text, runtime index or automatic download. Exact-preserving RRF-60 is the only hybrid prototype. Vector-only is a diagnostic ablation.

The corpus is intentionally repetitive/self-authored, not an independently judged semantic benchmark. Relevant ID sets include all eligible repeated statements; Recall@10 uses the full relevant-set denominator, while Hit@10 is “any relevant item in top ten.” A query can therefore have exact Top-1=100% and low Recall@10. Positive metrics exclude the 20 N negatives and four P probes; each appears separately. G/H are conservative state-label tests, not a measure of full logical entailment. No candidate was trained/tuned on production data. No model passed the quality gate; browser model startup/device compatibility were not claimed.

Chinese cross-check: install onnxruntime==1.23.2 (development only); download pinned bge-assets.json using download-bge.py, then run bge-prototype.py. It expects /private/tmp/paia-v0110-bge. No runtime/model assets are packaged. It uses the same prefiltered synthetic pool and frozen lexical rankings. Full positive gains and failed negative/latency gates are retained, not discarded because the model was rejected. The vector lifecycle helper is not the benchmark matrix and is not integrated with Source deletion.
