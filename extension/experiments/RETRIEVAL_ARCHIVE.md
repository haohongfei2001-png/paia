# Archived VS-07 semantic retrieval experiment

status: EXPERIMENTAL / DEFAULT_OFF / NON-BLOCKING
owner: PAIA VS-07 evidence archive
production_admission: NONE

The fixed public synthetic corpus, candidate-model reports, source/provenance
screens, evaluator scripts, derived-index prototype and owning tests remain
available for future optional study. The local semantic retrieval model is not
a PAIA Consumer Product v1 prerequisite or a production search backend.
These modules live under `extension/experiments/`, outside the packaged
extension runtime directories. Do not import them from production UI, Context,
service worker or Search. The prior automated VS-07 retrieval-model workflow
is retired; no new model, threshold or ranking study is part of v1 closure.

Actual retained evidence includes PAIA Candidate Gate run 36378886166 at
17f109cddb0c944fcf17bdcf62f92dad4e92e308 (all affected jobs SUCCESS;
the hosted Chrome experiment used 1025 complete Sources, 17 long bodies and
11 complete synthetic-encoder hybrid queries). The fixed public DistilUSE
measurement did not meet production quality admission. These observations
do not prove a useful production semantic model, blind answerability,
model-load resources, or process peak memory.

The default PAIA v1 search remains the VS-04 local algorithmic path with
explicit scope/filter/source authority. Semantic Lab is reserved exclusively
for `Input → Topic` Topic Router research. PAIA will consume an approved
versioned contract if that capability is later supplied; this retrieval archive
does not duplicate its research or imply classifier admission.

Future optional semantic retrieval needs a separate product decision and
quality, resource, privacy, compatibility and exact-runtime certification.
