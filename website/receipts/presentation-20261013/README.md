# PAIA 首页：自然浏览，不是缩小的产品模拟器

负责人批准将首页改为观看优先。沿用现有蓝白视觉、标题、主要段落、原始示例和日期/来源；删除“试着编辑、搜索、打开、返回、还原”等本页试用指引和控件。完整实际编辑、搜索、来源核对、提示词管理和 Context 许可操作仍由独立 `demo.html` 保留。获取、帮助、联系和其他内容页未改写。

首页由原设计素材在构建时投影成独立的只读 HTML：没有 textarea/input/select、伪装按钮、个人详情子树，也不加载原模拟器控制器。导航、获取/演示链接及明确的手机公开链接复制继续可用。此处不是用 CSS 隐藏可编辑私密 DOM。

桌面保留 0/110/320px 的阶段验收：矩形主题 → 同框原话 → 同框整理；同一锚点的球 → 胶囊 → 窄板，最后显示非输入框的表达复用示意，绝不自动发送。手机所有主题都在正常纵向文档中，接续同一个阅读矩形与固定的聊天示意，滚动就能完成主要展示，无切换按钮或吸顶闸门。减少动态与无 JS 使用完整、可读的稳定结果。

AI Context 保留四个目录及元数据，个人正文和详情根本不进入首页 HTML。所有演示内容为沿用的合成示例，不读取档案或真实聊天、不调用 AI 或写入权限。

## 验证边界

`website/presentation_invariants.json` 用原始 Git 基线锁定非首页生成页面、原演示控制器与主要视觉资产；正文的源字句仍使用原 `launch_invariants.json`，只是把 textarea 选择器映射到正文段落，不重记假基线。原编辑、光标、输入法、权限、触控/键盘及来源断言在独立演示页继续执行，首页则验证无需点击的原生滚动、同框/锚点一致、无可写字段、无服务调用和无 JS 可读。旧几何/光感基线的非冲突条件继续保留。

截图来自本地 HTTP 页面，不代表真实扩展、模型服务或物理设备全面认证；合并与正式发布状态以 PR/CI/Pages 的最终记录为准。没有真实联系留言、邮件或 AI 调用。
