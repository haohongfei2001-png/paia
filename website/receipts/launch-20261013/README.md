# PAIA — 正式产品官网收口

本轮依据负责人“按最终产品表达，不反复说明开发状态”的明确指示。

## 变化

- 使用精确双语文案表替换 89 组表述，移除主页面的内测、规划与开发过程说明。没有全局删除“第一版”等词，因此示例用户的项目判断、四条完整原话与来源没有被改写。
- 主导航收为产品／使用场景／如何使用／帮助。首屏主按钮通往“获取 PAIA”，副按钮通往交互演示；关于与文章移至资源导航。
- 新增 `download.html`、`help.html`、`contact.html` 的中英文及旧英文别名，生成文件由50变为59。旧 `beta.html`、`status.html` 仍可访问，分别以获取／帮助为规范地址，退出 sitemap，不再展示工程进度矩阵。
- 保留已有表单控制器、服务与收件方，改为明确同意的联系留言用途。服务接收仍不等同于实际收件箱送达；不自动重试、不发送真实邮件作验收。
- 隐私和使用说明与实际联系用途同步，数据许可、原始来源、访问撤回、同步生态边界保持。没有新增分析追踪、账号、付费服务或处理权限。

## 保留

首页主标题、价值描述、所有原话及其时序，通过 `launch_invariants.json` 与本轮起始 main 对照。原有球／胶囊／浮板锚点、玻璃整理矩形、滚动阈值、输入和权限控制器，以及它们的样式源码逐字节不变。品牌字标、图标、配色与光感不重做。

历史文案冻结文件 `art_direction_baseline.json` 保留，不伪装成仍通过旧文案。负责人已批准的新版由 `launch_baseline.json` 单独冻结；原有业务、权限、原话、锚点、鼠标滚轮、IME、无发送、对比度及200%文字检查仍保留，新增正式入口检查作为补充。

## 安装边界

库内与公开 Releases 未找到已核验的正式安装地址。`launch_manifest.json` 的地址保持空值。获取页因此只在实际安装动作旁说明“安装入口尚未开放”，不会伪造商店链接或把下载动作导向报名表。演示与帮助仍可用。未来接入已核验的具体 Chrome Web Store 地址即可，不必再改写整站。

这是官网的成品表达与使用路径，不是扩展、真实 AI、云同步或收费服务已完成的证据；不改变任何产品 Canonical、扩展代码或 GitHub 工作流。
