# PAIA 官网整站重构 · 2026-10-09

本次按 Owner 的整站设计与实施授权完成。原官网（包括 PR #213）是需要
重新审视的基线，不是必须保留的视觉标准。网站分支为
`feat/website-full-refoundation-20261009`；起点是 main
`ca11a1e4cd794e95f2ad515f5d197da9bef4d833`。范围仅包含官网、网站验证和交付证据。

## 设计决策

### 1. 用真实产品比例组织首屏

桌面首屏从居中大标题加通栏窗口，改成叙事与产品并置的构图。1440px 视口下，
产品玻璃窗口由 **1160 × 538（2.156:1）** 改为
**760.5625 × 518（1.468:1）**。Reader 正文提高到可读字号，侧栏、导航和元信息
分别占据合理宽度；没有用缩放整个大桌面截图来挤进网页。

手机改为可操作的三空间标签与单列内容，不把桌面的三栏压成细小文字。
Hero 标签为 11px，主要 Reader 正文为 15px；完整交互 Reader 为 16px。
320px 与双倍文字使用自然换行，导航、申请入口和菜单不会互相覆盖。

### 2. 材质承担空间关系

冷白阅读面、蓝灰结构线、光学边缘与少量磨砂表面构成同一系统。玻璃用于
悬浮导航、产品外层、提示词伴随面板和范围预览；正文与主题块保持稳定。
产品后方的几何反射面有明确边缘和方向，不使用粒子、无意义光球或模板插画。

PAIA 原字标继续使用品牌字体。产品 UI 与中文主标题保持清晰的无衬线；
英文品牌、文章和说明页使用独立的 Instrument Serif 展示字体，形成阅读节奏。
Reader 的标题和连续阅读角色继续与外层官网标题区分。

### 3. 全站有共同语言，也有不同结构

| 页面 | 新结构 |
|---|---|
| 首页 | 产品并置首屏、三空间切换、四段真实交互、范围说明与品牌收束 |
| 如何使用 | 留下、找回、积累、复用、接续五步，沿同一示例逐步展开 |
| 使用场景 | 长期项目、研究问题、重要选择：已有表达与下一次任务的对照 |
| 交互 Demo | 紧凑入口与唯一示例披露，复用可操作的虚构产品示例组件 |
| Beta | 明确申请表、转发同意、申请后步骤及不提供邮箱的示例入口 |
| About | 品牌表达、三个产品空间、设计信念；女孩、旧信箱和信只在原点章节出现 |
| Blog / 三篇文章 | 主文章与次文章的层级、章节目录、引语与阅读导航 |
| 数据与权限 | 本地档案、AI 整理、外部读取、个人云同步四种独立选择 |
| 可用范围 | 网页示例、邀请制构建、已批准但仍在完成的能力分别说明 |
| 隐私、条款、返回、404 | 统一阅读版式、目录与明确返回路径；保留既有实质条款和表单边界 |

共 16 类页面，32 条中英文 canonical 路由及 16 条兼容 `/en/` 路由。
50 个生成文件包含 48 个 HTML、sitemap 和 robots。

### 4. 动效由阅读和操作产生

默认展示原生滚动的空间位移、有限入场、导航当前章节、产品面板切换、
提示词填入反馈与范围状态转换。没有普通用户的“暂停动效”开关、滚动劫持、
必须等动画结束的内容门槛或持续空转的渲染循环。

系统减少动态效果会关闭动画与过渡，切换系统偏好也立即生效。查找退出的
滚动恢复在布局与焦点稳定后完成；高对比模式保留按钮边界和非颜色状态标记。

## 产品依据与准确性

正式依据见 [产品能力映射](../PRODUCT_CAPABILITY_MAP.md)。本次实际读取并核对了
当前 AUTHORITY / STATUS、Archive IAH-1.1、Thought PT1、Context 四卡 v2、
Prompt Reuse / Stage 3A 等合同和实现，实际解码查看了可访问的 D6 A02 Reader
与 Prompt v2 材质参考。

- Archive 示例是已选中的虚构会话。Reader Find 保留完整输入，以匹配输入为单位
  定位与步进；清空和 Escape 恢复阅读位置。中列全档案搜索是静态结构示意，
  不应被当成网站已实现的全库查询。
- Thought Root 只呈现个人 Topic 和普通 Section 名称；进入同一主题的连续章节，
  没有新增章节首页、摘要卡、类别总览或候选审批路径。
- Context 的演示用户已授权四卡及两个主题。真实首次使用默认关闭、全局／卡片／
  Topic 分离、关闭不删除独立内容、下级不暗开上级等规则保持不变。
- Prompt 行直接显示填入的完整个人说法；可靠光标和选区末端被保留，未知位置
  才追加末尾。草稿与选中文字不会被替换，也不自动发送。
- 预设的 AI 阅读和建议明确属于网页示意，不伪装成新模型结果或真实连接。
