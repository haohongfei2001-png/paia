## 实际交互与边界

滚动动画使用本页模拟数据，不调用 AI，不读取实际聊天、档案或设备资料，不发送消息。思想库第三阶段是 **规划能力的预设示意**，不是已实现的自动知识图谱；主题、章节与原话始终可打开阅读。提示词胶囊内容来自本页既有个人提示词示例，不是现时 AI 模型生成结果。滚动阶段仅提供视觉上的“填入预览”，**不会覆盖现有输入草稿，也不会自动发送**；真正填入必须点击确认。

桌面端使用原生滚动、有限阶段转换与 transform/opacity。失焦、后台更新和普通滚动不改变用户主动开启的浮板状态。移动端与系统减少动态偏好优先确保内容和控件可达，取消过长的吸顶动画，不制造滚动闸门。

Context 原有四卡片、全局开关、独立权限与本页 scope 预览全部保留，只将底部的重复大展示折叠到“查看授权范围和说明”，因此没有丢弃权限解释或减少撤回能力。

GitHub Pages 发布后应核对中英文生产路由、当前首屏、实际动画、移动端、表单边界与精确部署字节。静态截图和本地浏览器测试不代表真实扩展或 AI 服务认证。
