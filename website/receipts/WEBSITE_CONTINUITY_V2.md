## Request and baseline

critique: stronger cases, a convincing long-term Thought experience, consistent

## Implemented story

Three explicitly fictional cases contain 18 source expressions, each covering
six distinct conversations across more than six months. The independent project
is a quoting tool, with unresolved demand, revision limits, rejected automatic
pricing, an interaction to test and a next decision. Research separates a
hypothesis from evidence and untested conditions. Career distinguishes titles,
actual work, fixed requirements and changing priorities. These are neither
private user records nor claims of adoption or measured product results.

The opening offers two actual presentation controls for the same two original
expressions. A real sample search supports matches, highlights, clearing and
an empty result. The main reader moves identical original DOM nodes between
preset topic sections and actual chronological order. Native disclosures keep
mobile reading manageable; no content is clipped or discarded. All original
expressions remain readable without JavaScript.

The old judgment can be explicitly quoted into a new sample draft. Saved phrases
are visible by default. Selection-end insertion preserves selected and other
draft text, active composition and the length limit; nothing automatically sends
or persists. Case switching does not rewrite the draft. The small-screen quote
action reveals its result only after successful user-requested insertion.

Use cases and How share the same records. The independent full Demo uses the
same project with a May8 conversation and a later September24 decision. Its
controller differs only in declared synthetic text literals; no input, source,
permission, IME, focus, capture or transport logic was changed.

## Retained boundaries and sources

Navigation material, identity assets, original orb artwork, four-card Context
and the exact original closing are preserved. The entire closing HTML is
compared with the actual preceding Git object. Actual installation remains
unavailable under the unchanged manifest. No model, cloud sync, external Context
connection, product implementation or real permission is activated.

`continuity_preserved.json` hashes the retained source/asset owners.
`continuity_runtime_copy.json` enumerates sample-only runtime substitutions;
reversing them must yield the original runtime digest. The full Demo core test
file is likewise compared after restoring only its expected fictional title.
Old homepage-specific layout assumptions dispatch to new semantic tests. The
original full Demo, form-consent, keyboard, source, permission, IME, all-route
reflow and asset checks remain in the original website suite.

No extension, service, private archive, provider configuration, release manifest
or GitHub workflow is modified. No contact message or real service call is sent.

in both languages, including Home, How, Use cases, Demo, all three cases, the
