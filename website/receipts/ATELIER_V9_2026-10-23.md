# Atelier V9 homepage publication — 23 October 2026

## Authorized scope

The owner requested a less rigid Thought Library presentation, a new hero
background while retaining the rest of the approved design, and publication on
the existing official PAIA website. This continues the conversation V8 artifact;
it does not adopt the earlier rejected website drafts.

Baseline main: `3bbd033b760701b5267a813d23ea94d26760c3b0`.
Existing Pages source: main, repository root, `https://inputarchive.com/`.
The isolated worktree protects the owner's existing checkout and its untracked
extension files. No extension, service, account, permission, workflow or release
manifest changes are included.

## Implementation

The root English homepage, its `/en/` alias, and `/zh/` are generated from the
paired `website/atelier/` templates using the existing build. New runtime assets
are confined to `assets/website/atelier/`, with a locally hosted OFL font subset.
Old interior pages, original brand assets, independent demo and contact consent
are byte-locked by `website/atelier/preserved-files.json`.

The approved R3 geometry/code remains exact; English changes only its text.
The homepage now handles Escape for an open Context modal before the global
floating component, fixing a real focus-replacement interaction defect.
All example data is fictional, page-local and nonpersistent. AI organization is
a preset demonstration; there is no model transport or real Context grant.

## Test migration and retained failures

Historical home-only pixel/copy freezes apply to the old homepage and are not
misrepresented as tests of this owner-requested replacement. The new home has its
own scoped checks; all original interior, standalone-demo, IME/input, contact,
asset-integrity and availability checks remain.
Early pre-PR browser runs exposed incorrect selectors in the new test and a
768px menu-breakpoint assumption. Those expectations were corrected against the
actual DOM/visible control. The modal Escape issue was an implementation defect
and was repaired, then independently reproduced and verified. Earlier failed
runs remain failed and are not relabelled as successes.

This evidence concerns the website only. It is not certification of an installed
extension, live model integration, synchronization or physical-device behavior.
