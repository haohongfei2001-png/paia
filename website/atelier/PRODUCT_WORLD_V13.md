# Atelier V13 — show the product, not a parade of minor features

Owner direction: rebuild the core presentation around a coherent product story,
with expressive but harmonious art direction. Small affordances belong in small
cards; the main scenes should make a personal body of expression feel organized,
valuable and desirable. Do not merely repeat another optical-polish pass.

Baseline main: `c7fcea4ce777c5426090bdefeadb629426bde9c5`.
Isolated website worktree. No extension, connected account, actual AI processing,
permissions, services, installation availability, contact transport or workflow
changes. The current V12 interactive demo and all interior pages are unchanged.

## One narrative

1. The original hero and manifesto remain exact.
2. Input Archive becomes a broad personal collection of actual fictional sent
   expressions, not a standalone search utility. Search is a small proof below.
   The opt-in requirement is explicit. The art does not claim full-history import.
3. Thought Library shows three actual topic/section directories and one complete
   reading section: Product / The first step. Two entire existing sample inputs
   appear in their real newest-first order. Root cards contain titles/chapters
   only; no source actions, excerpts, summaries, counts or invented taxonomy.
   It links to the actual matching `demo.html#topic-reader` default section.
4. The approved Context quartet follows as the next-use outcome. Its geometry,
   pigments, content/permission distinction and independent default-off controls
   are retained. Only a short narrative bridge is added ahead of the old block.
5. Reuse, direct editing and the approved private-space orbit form one compact
   detail ensemble under the existing everyday-use anchor. The additional
   full-page daily example is removed instead of repeating the reuse promise.
6. Original closing story, illustration and true installation boundary remain.

## Art direction

The archive's varied content surfaces sit in one precise, lightly framed plane.
The library uses a different open composition: topic directories and a chapter
in front of an unbounded soft-color field. Both use the same typography roles,
fine edges, restrained depth, and blue/rose/sand accents. Typography is rendered
as accessible HTML, not a flattened image. No borrowed competitor assets, fake
customer claims or new product capabilities are introduced.

The new homepage-only `world13.css` owns these compositions. Earlier files stay
byte-identical because the approved hero and Context still consume them. All
old assets and non-home outputs are locked in `preserved-v13.json`; preserved
hero, manifesto, Context cards, privacy artwork and closing story additionally
have exact fragment hashes. New CJK subset extends the same licensed Noto Serif
SC Light family for public fictional copy; existing OFL license is retained.

## Motion and actual operations

`presentation13.js` retains the previous subject-visibility start, finite elapsed
clock, pause/replay, offscreen/hidden handling, reduced-motion final state and
manual R3 takeover. It owns three scenes, not five repetitive standalone ones.
All required content is visible without playback, JavaScript or interaction.
Motion never rewrites a sentence, replaces its node or creates an AI output.
Only one replay control remains visible at rest.

The original R3 implementation and its six-row board remain byte-identical.
Its homepage adapter writes only into a readonly fictional draft. The unchanged
interactive demo retains actual editing, IME and caret insertion tests.

## Verification

The unchanged workflow commands remain:
`python website/build.py --check`, `python website/test.py`, and
`python website/verify_live.py` after publication.

The new `world13_checks.py` tests the current art structure instead of asserting
retired screenshot selectors. It preserves independent permissions, focus,
node/text identity, finite/reduced motion, real R3 interactions, no transmission,
no persistence and no-JavaScript content. Existing demo editing/IME/layer tests,
all support/legal/form-consent checks and installation guards still run.
Rendered screenshot review is separate from these assertions. Website checks
are not evidence of physical-device quality, field performance, user research,
installed-extension behavior or objectively top-tier visual design.
