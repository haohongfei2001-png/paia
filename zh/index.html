01 / CONTINUITY

一次对话是一个时刻。
思考不是。

PAIA 不把你的长期表达压成一个永远正确的个人档案。它保留时间、来源和修改之间的区别，让不同阶段的你可以同时存在。

01一次表达

提出问题、给出背景、做出判断。

02后来修改

今天的工作版本，不冒充昨天的原话。

03形成脉络

跨会话看见同一件事如何延续。

04再次使用

按这次任务选择，而不是把全部历史交出去。

02 / SELECTION

Context 是一次选择。
不是永久画像。

算法可以帮助找相关材料，但不能替代你明确选中的内容。准备 Context 时，选择、审阅、修改，然后才复制或导出。

03 / OWNERSHIP

先属于你。
再用于 AI。

01LOCAL

普通阅读、编辑、词面搜索与 Context 准备尽可能在设备本地完成。

→
02SELECT

保存，不等于授权。过滤、删除、主题归属和给 AI 使用是不同的动作。

→
03PREVIEW

看清这次准备的完整文字，修改后再决定下一步。

→
04COPY / EXPORT

当前复用通过复制或导出。真实外部 AI 读取连接器仍是未来方向。

来源事实、你的工作版本、AI 整理结果保持区分。今天的修改，不会被冒充成你过去说过的话。
