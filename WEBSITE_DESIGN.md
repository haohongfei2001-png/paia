# PAIA website — implementation authority

The owner has authorized implementation of the later selected composition and
its text-first / scroll-collected-input sequence. The previous 90-artboard
`design/website-editorial-v1` package was rejected in subsequent visual reviews;
it is historical and must not be treated as the approved implementation target.

The current public website source and behavior are documented in
[website/README.md](website/README.md). Exact engineering/visual evidence belongs
in [website/receipts/WEBSITE_V4.md](website/receipts/WEBSITE_V4.md).

The selected visual invariants are: spacious serif-led first frame; gradual input
collection; faithful SVG source marks; custom line artwork; unequal layered
cards and fine connecting curves; one useful interactive product example;
purposeful architecture at the close. No dense feature catalog, empty slogans,
fictional testimonials or dead video links. Marketing capability claims remain
constrained by current extension canonical documentation, not by mockup copy.

The full-site PDF and motion-keyframe exports are generated from the actual HTML
by `website/export_pdf.py`, not by assembling concept images.
