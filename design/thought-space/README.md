# PAIA — thought-space visual direction

Standalone owner-requested design response to the rejected paper/pinboard study.
This is an unlinked, noindex visual prototype. It does not replace the official
homepage, change the installed product or claim an approved new product UI.

## Material and composition

One large transparent chassis, restrained bevels and contact shadows, a coherent
light field and fine line-reliefs. The same three topic directories are shown
inside a single perspective space. Native scrolling moves the camera toward the
surface, condenses the directories and brings an opaque reading plane forward.
The final reading view is front-facing and unscaled where viewport space allows.
This is not a stack of paper cut-outs or independent 2D rotated excerpts.

The original PAIA mark, current headline, current topic/chapter names and two
complete existing fictional Product/First step entries remain. Directory art is
decorative, not an implied relationship graph or an extra product feature.
There are no recurring source controls, app searches, invented data counts,
model outputs, grants, editing workflows or installation promises.

The bottom controls select a presentation viewpoint, not an app feature.
Natural scrolling is neither intercepted nor locked. Text and its DOM identity
are unchanged while the camera/geometry move. There is no continuous idle loop.
Reduced-motion and no-JavaScript alternatives show the complete reading state.
All assets stay on the existing origin; existing font files are referenced, not
copied, bundled for distribution or replaced. No competitor asset is embedded.

## References inspected

- https://mymind.com/ and https://mymind.com/why — scale, fine graphic lines,
  expressive typography, coherent environmental color.
- https://www.craft.do/customize and https://www.craft.do/write — clean product
  surfaces, translucent chrome, precise content hierarchy.
- https://sublime.app/ — unity between a brand's central visual and its content.
- MDN CSS perspective(), transform-style, backdrop-filter — implementation and
  compositing boundaries. Glass is limited to the shell/navigation; prose is not
  blurred or placed on unstable background textures.

## Verification

`check_preview.py` accepts PREVIEW_URL, PREVIEW_OUTPUT and CHROMIUM_EXECUTABLE.
It checks six viewport sizes, scroll/reverse state, content-node continuity,
controls, static/reduced-motion/no-JS output and lack of external transmissions.
Actual screenshots were reviewed separately. Browser correctness is not a claim
that this design has equalled or exceeded the named references.

Scope: only this directory is added. Official root/Chinese/English homepages,
product demo, all pre-existing assets, workflows, contact consent, installation
manifest and extension code remain byte-identical to the existing main.
