## 设计结果

第一幕保持现有首屏。第二幕在同一舞台上依次聚焦档案、矩形主题、同框阅读与整理、固定锚点的悬浮工具、四个 Context 目录，最后让原先的对象回到全景。第三幕保留现有结尾与页脚。

AI Context 只包含目录与功能性说明，不展示私人正文。输入区为只读示意，不发送消息、不调用 AI、不操作私人资料。

总览使用“PAIA / 三个空间，同一份积累”。这是编辑式能力回顾，不冒充实际产品中的统一控制台。

桌面中段为3120px原生滚动，末端有430px稳定总览区；小屏与减少动态使用正常文档，不缩小完整桌面来冒充适配。
