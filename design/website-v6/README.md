# PAIA Website v6 — Origin-led design study

This branch is deliberately design-only. It does not modify root website HTML, website generators, public CSS/JS, deployment configuration, extension code, product STATUS or PR #88.

The v6 review package is built around the original approved visual language rather than the rejected v5 direction:

- text-first opening with large intentional whitespace;
- source cards emerge under native scroll instead of appearing as a dashboard;
- accurate provider marks and unequal spatial composition;
- relation paths only where they explain context formation;
- light product scene instead of a dark “tech” panel;
- no decorative stock photography, empty slogans, fake AI capability or testimonial content;
- mobile adapts to a staggered vertical spatial sequence rather than forcing desktop overlap.

Visual artboards and the motion study are review attachments for the owner. They are not production evidence. The binding design rules are in `V6_DESIGN_CONTRACT.md`.

Do not implement this direction until owner visual approval.
