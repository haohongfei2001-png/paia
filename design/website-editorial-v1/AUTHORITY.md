## Product model used in the copy

PAIA is a personal AI input, thought and context system. The first visible value is a working archive of what a person says to AI. The loop is Capture → Revisit → Understand → Reuse; organization is an enhancement, not maintenance the user must complete before receiving value. A person using only one AI product can still have cross-conversation discontinuity.

Source facts, working edits, optional AI presentations and selected context have different roles. “The user sent this” is not evidence that the user believes every quoted passage. Historical instructions are archive content, not current authorization.
